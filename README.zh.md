# dsh-fail-guard

[English](README.md)

独立的 DSH 防护插件：连续工具失败时发出停手通知，思考段出现连续复读时截断。只需要安装本包；一个宿主条目、一份配置、一个插件详情页。

## 从 dshmarket 订阅安装

在 dshmarket 已有的 **FenrirCait/dsh-fail-guard** 条目中订阅／安装，完成后按市场提示重载或重启所选 DSH profile。无需额外安装旧守卫，也无需手写 Cordis 配置。

当前生成目录把本条目映射到预构建 npm 包，实际安装命令为：

```sh
dsh plugin --profile desktop add dsh-fail-guard
```

要让该市场订阅收到新版本，还需将对应版本发布到这个 npm 包；只推送 Git 不会更新 npm 分发。如果主动选择 GitHub 源码安装，则使用：

```sh
dsh plugin --profile desktop add github:FenrirCait/dsh-fail-guard
```

本仓库自带 `lib/` 中的预构建宿主与浏览器文件，订阅用户无需构建或安装开发依赖。维护者准备更新时应把这些生成文件一并提交；`dsh.bundle.patch` 自动声明唯一的 Cordis 入口。验收宿主基线为 DSH 0.2.2-rc.5；声明的 peer 范围内其他版本未逐一测试。

## 设置

打开 **插件 → dsh-fail-guard → 详情**。新条目 ID 为 `dsh-fail-guard-standalone`，不读取、不迁移旧设置。

- **失败防护**：默认开启。同一轮内同一工具连续失败 3 次时通知，成功或换工具会中断计数。通知不是强制中止。
- **复读打断**：默认开启。同一思考块内连续 5 个符合条件的相同行可触发截断；不改写正文，不记录思考原文。
- **自动续跑**：默认关闭。开启后每轮最多一次；若本轮已通知停手，则不续跑。

「仅观察」默认关闭。开启后，两项防护仍按相同规则检测，但只在会话回合末显示命中说明，不截断、不向模型发送停手通知、不自动续跑。说明只记录回合、规则、次数和动作。流的活动块超过 64 时，本条流停止检测，保持原样透传。

### 短碎片观察（实验）

在详情页的「实验功能」中开启「观察短碎片复读（实验）」并保存。默认关闭，独立于连续复读防护和全局「仅观察」开关。遇到密集重复的短碎片（含交替、跨块和单行连写形态）时，每回合最多显示一条计数摘要。该实验不提示模型、不截断、不续跑；摘要不保存思考原文、哈希或会话标识，也不写入自动诊断报告。

这是用于校准的观察规则，不是完整的空转检测：超长行或活动块超限时停止观察、继续透传；没有换行的单行样本要等到思考块结束才判断。现有自检只覆盖连续失败和连续复读。

### 其他实验功能

四项均默认关闭、逐项启用。模糊复读仅记录同一思考块的近重复完整行；跨轮连败仅记录相邻回合中同工具、同参数、连续失败的回合数，两者不改变生成或工具行为。跨轮窗口为两分钟，换操作、成功或证据不完整时清零。模拟停手只记录本轮同一操作的连续失败，不取消工具或回合。主动引导只在原精确复读已截断后排队，每回合最多一次；仅观察模式下不触发，旧自动续跑优先。「已排队」不等于模型已收到或恢复。实验摘要不包含参数原文或操作指纹。

### 本地反馈

在已完成回合展开「防护诊断 → 标记防护反馈」，选择一条规则。有命中记录时可标「命中正确」或「这是误报」；没有可用记录时可以「报告漏报」。缺少记录不代表规则当时关闭或运行过；是否开启可按记忆填写，也可留为不确定。先预览 JSON，可取消导出插件版本、命中计数与处置，再点击「下载反馈 JSON」，自行决定是否分享。

反馈文件不含会话内容、会话标识或诊断备注，不自动上传；原手动、自动诊断报告的格式不变。

## 沙盒试装与回滚

以 DSH 0.2.2-rc.5 为验收环境。试装前备份 sandbox 的包清单、锁文件和配置补丁，以 `dsh plugin --profile sandbox add <候选.tgz>` 安装并重启该 profile。不需要另外安装旧版复读守卫。回滚时重装保存的旧包；若配置补丁有变化，再从快照恢复并重启。
